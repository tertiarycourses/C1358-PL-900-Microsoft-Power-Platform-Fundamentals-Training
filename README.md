## About the course

Microsoft Power Platform lets the people who understand the business build the solution, without
waiting for a development team. Over two days you learn to identify where Power Platform can
connect systems that were never designed to talk to each other, build apps and automations on
that data, test and verify that the integration works, and diagnose and fix it when it does not.

Every lab builds one part of a single running case study — **Contoso Corporation's facilities
request system** — so by the end of the course you have one complete, working solution rather
than fifteen disconnected exercises.

## Learning outcomes

On completion of this course you will be able to:

- **LO1** — Identify opportunities and assess Power Platform for connecting various devices,
  databases, software and applications.
- **LO2** — Utilise Power Platform to integrate data, functions and supporting API-level
  integration.
- **LO3** — Perform tests and verify the functioning of Power Platform applications.
- **LO4** — Highlight and address technical, compatibility or performance issues following the
  integration of Power Platform.

## What you need

- A Windows laptop with a modern browser (Microsoft Edge or Google Chrome).
- A Microsoft 365 work or school account with Power Platform access, or a free
  [Power Apps developer environment](https://aka.ms/PowerAppsDevPlan).
- A Power Platform environment with Microsoft Dataverse provisioned, and maker-level permissions.
- Power BI Desktop installed (free from the Microsoft Store) for Topic 5.
